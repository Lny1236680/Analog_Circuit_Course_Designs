# 多功能音频功率放大器

模拟电子技术课程设计。在**禁止使用专用功放 IC**（允许通用运放）的约束下，设计并仿真一台 1 W 级、20 Hz–20 kHz 的音频功率放大器，带音量调节与高低音音调控制。

## 设计指标

| 项目 | 指标 |
|---|---|
| 最大不失真输出功率 | P_OM > 1 W（8 Ω 负载） |
| 频带宽度 | 20 Hz – 20 kHz |
| 音调控制 | 低音 100 Hz ±12 dB，高音 10 kHz ±12 dB |
| 音量调节 | 0 ~ -∞ dB |
| 器件限制 | 禁用专用功放 IC，可使用集成运放 |

## 系统架构

```
音频输入 → 输入缓冲(U1A, Av=1) → 有源 Baxandall 音调控制(U1B) → 音量电位器 → 功率放大级(U2+互补管) → 8Ω 扬声器
                                                                          ±15V 双电源
```

- **输入缓冲级**：NE5532 电压跟随器，输入阻抗 47 kΩ，输入耦合 2.2 µF（f_L ≈ 1.5 Hz）；
- **音调控制级**：反馈式 Baxandall 网络，低音 100 kΩ 电位器 + 33 kΩ/47 nF（102.6 Hz），高音 100 kΩ 电位器 + 33 kΩ/470 pF（10.27 kHz）；
- **功率放大级**：NE5532 驱动 TIP41C/TIP42C 互补射极跟随器，AB 类偏置（2×1N4148），射极电阻 0.47 Ω，负反馈增益 `Av = 1 + 22k/750 ≈ 30.3`。

## 关键计算

| 项目 | 计算 | 结果 |
|---|---|---|
| 输出要求 | `V_rms = √(P·R_L)` | 2.83 V（峰值 4.0 V、峰值电流 0.5 A） |
| 电源电压 | 峰值 4 V + 管压降余量 | ±15 V |
| 功放级增益 | `1 + R8/R10` | ≈30.3（29.6 dB） |
| 输出功率 | `(3.03 V)² / 8 Ω` | ≈1.15 W > 1 W |
| 闭环带宽 | `GBW/Av = 10 MHz/30.3` | ≈330 kHz ≫ 20 kHz |
| 低音转折 | `1/(2π·33k·47nF)` | 102.6 Hz |
| 高音转折 | `1/(2π·33k·470pF)` | 10.27 kHz |

完整推导、BOM 与供电方案见 [`docs/设计文档.md`](docs/设计文档.md)。

## 复现

1. 用 Multisim 14.x 打开 `multisim/多功能音频放大器.ms14`；
2. 或新建工程后 `文件 → 打开` 导入 `netlist/audio_amplifier.cir`（网表不含元件坐标，导入后需手动排布）；
3. 按 [`docs/Multisim仿真步骤.md`](docs/Multisim仿真步骤.md) 依次运行瞬态、AC 扫频与失真分析。
