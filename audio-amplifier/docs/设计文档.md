# 多功能音频放大器设计

## 设计要求

| 序号 | 设计要求 | 指标 |
|------|---------|------|
| 1 | 最大输出不失真功率 | P_OM > 1W |
| 2 | 频带宽度 | BW = 20Hz ~ 20kHz |
| 3 | 负载 | 8Ω 扬声器 |
| 4 | 音量调节 | 有 |
| 5 | 音调控制 | 低音 100Hz ±12dB，高音 10kHz ±12dB |
| -- | 限制 | 禁止专用集成芯片，可使用集成运放 |

---

## 一、整体架构

```
                        双电源 ±15V 供电
                                  │
                                  ▼
 音频输入 ──▶ 输入缓冲(U1A) ──▶ Baxandall音调控制 ──▶ 音量电位器 ──▶ 功率放大级 ──▶ 8Ω扬声器
                增益=1              低音±12dB@100Hz       0~-∞dB      (U2+互补管)
                                   高音±12dB@10kHz                    增益≈30倍
```

---

## 二、关键参数计算

### 2.1 功率放大器输出要求

- P_OM > 1W，负载 R_L = 8Ω
- 输出电压有效值：V_rms = √(P × R_L) = √(1 × 8) = **2.83 V**
- 输出电压峰值：V_peak = √2 × V_rms = **4.0 V**
- 输出电流峰值：I_peak = V_peak / R_L = 4.0 / 8 = **0.5 A**
- 电源电压选择：**±15V**（留足够动态余量）

### 2.2 输入信号

假设输入为线路电平（Line Level），V_in ≈ 100mV_rms（0.141V 峰值）

功率级增益需求：A_v = V_out / V_in = 4.0 / 0.141 ≈ **28.4 倍 (≈29dB)**

---

## 三、各级详细设计

### 3.1 输入缓冲级 (U1A)

- 运放：NE5532（双运放，低噪声，U1 的第一路）
- 接法：电压跟随器（同相输入，输出接反相输入）
- 增益：Av = 1 (0dB)
- 输入阻抗：R1 = 47kΩ 对地
- 输入耦合电容：C1 = 2.2µF（与 R1 构成高通，f_c ≈ 1.5Hz << 20Hz ✓）

```
          C1 2.2µF
 输入 ────||────┬──── U1A 同相端(+)
                │
               R1 47kΩ
                │
               GND
```

### 3.2 音调控制级 — 有源 Baxandall (U1B)

采用反馈式 Baxandall 拓扑，调音网络置于运放 U1B（NE5532 第二路）反馈回路中。

#### 3.2.1 低音控制网络（100Hz，±12dB）

| 元件 | 值 | 说明 |
|------|------|------|
| P_BASS | 100kΩ (B型/线性) | 低音电位器 |
| R5 = R6 | 33kΩ | 固定电阻 |
| C2 = C3 | 0.047µF (47nF) | 转折频率电容 |

**计算验证：**
- ±12dB → 电压比 ≈ 4 倍 → P_BASS / R5 ≈ 3 → R5 = 100kΩ / 3 ≈ 33kΩ
- f_L = 1 / (2π × R5 × C2) = 1 / (2π × 33000 × 0.047×10^-6) ≈ **102.6 Hz ≈ 100 Hz** ✓

```
      C2 0.047µF              C3 0.047µF
  ──────||──────────────────────||──────
  │                                     │
  ├── R5 33kΩ ──┤               ├── R6 33kΩ ──┤
  │              │               │              │
  └── 电位器 P_BASS 100kΩ ──────┘
```

#### 3.2.2 高音控制网络（10kHz，±12dB）

| 元件 | 值 | 说明 |
|------|------|------|
| P_TREBLE | 100kΩ (B型/线性) | 高音电位器 |
| R7 | 33kΩ | 固定电阻 |
| C4 | 470pF | 转折频率电容 |

**计算验证：**
- f_H = 1 / (2π × R7 × C4) = 1 / (2π × 33000 × 470×10^-12) ≈ **10.27 kHz ≈ 10 kHz** ✓

#### 3.2.3 U1B 外围电阻

- R3 = R4 = 10kΩ（设定音调级基础增益，音调网络在其上叠加调节）

### 3.3 音量控制级

| 元件 | 值 | 说明 |
|------|------|------|
| P_VOLUME | 10kΩ (A型/指数型) | 音量电位器 |

位于音调级输出之后、功放级输入之前，采用分压式衰减。

### 3.4 功率放大级 (U2 + 互补输出级)

采用运放驱动 AB 类互补射极跟随器。双电源供电，输出直接耦合到扬声器。

| 元件 | 值/型号 | 说明 |
|------|---------|------|
| U2 | NE5532 或 TL072 | 驱动运放 |
| Q1 | TIP41C (NPN) | 上管 |
| Q2 | TIP42C (PNP) | 下管 |
| D1, D2 | 1N4148 ×2 | AB 类偏置二极管 |
| R9 | 2.2kΩ | 偏置二极管限流 |
| R8 | 22kΩ | 负反馈电阻 |
| R10 | 750Ω | 增益设定电阻 |
| R11, R12 | 0.47Ω / 1W | 射极稳定电阻 |

```
                        +15V
                         │
                   R9 2.2kΩ
                         │
                   ┌─ D1 1N4148
                   │     │
                   ├─ D2 1N4148
                   │     │
                   │    Q1 (TIP41C)
                   │   B/---E── R11 0.47Ω ──┐
                   │  /                      │
从音量电位器 ──────┤                        ├──── 输出 ──▶ 8Ω 扬声器
                   │  \                      │
                   │   Q2 (TIP42C)           │
                   │     E── R12 0.47Ω ──────┘
                   │     │
                   │    -15V
                   │
                   └────────── R8 22kΩ ──────┐
                                              │
                                        R10 750Ω
                                              │
                                             GND
```

**增益计算：**
- Av = 1 + R8/R10 = 1 + 22000/750 ≈ **30.3 倍**
- 输入 100mV_rms → 输出 3.03V_rms → P = (3.03)^2 / 8 ≈ **1.15W** > 1W ✓

**带宽确认：**
- NE5532 GBW ≈ 10MHz
- 闭环带宽 ≈ GBW / Av = 10MHz / 30.3 ≈ 330kHz >> 20kHz ✓
- 低频截止由输入耦合电容 C1 决定：f_L ≈ 1.5Hz << 20Hz ✓

## 五、供电方案

- **±15V 双电源供电**
- 推荐方案：变压器 → 整流桥 → 滤波电容 → 7815/7915 三端稳压 → ±15V
- 变压器次级：双 18V（中心抽头），功率 ≥ 10VA
- 滤波电容：2200µF/35V × 2
- 总功耗约 2-3W
