# 点光源跟踪器 — 控制原理课设

**纯模拟电路**（禁止编程器件）实现的二维点光源跟踪系统：光敏电阻差分检测光源偏差 →
LM358 差动放大 → TB6612 驱动直流电机 → 云台跟随光源。

## 核心结论

- 系统为 **I 型三阶位置伺服系统**，P 控制下对阶跃输入**零稳态误差**
- 相位裕度 **47.4°**，系统稳定
- 超调 20.6%，可通过增益/阻尼调节
- 增益 Ka 是稳定性核心权衡（Ka↑ → 精度↑但 PM↓）
