# 点光源跟踪器 — 系统方案

## 1. 设计目标

设计一个**纯模拟电路**（禁止使用单片机/可编程器件）的点光源跟踪系统：能感知点光源在
二维平面（左右、上下）的位置偏差，并驱动直流电机使传感器阵列始终对准光源。

- **双轴跟踪**：左右（水平 X 轴）+ 上下（垂直 Y 轴）
- **执行器**：直流减速电机 × 2 + TB6612 双 H 桥
- **传感**：4 个光敏电阻模块（左右 2 个 + 上下 2 个）
- **控制方式**：全模拟（光敏分压 → 差动放大 → H 桥驱动），无 MCU

## 2. 系统架构

```
                点光源
                  │ 光照
   ┌──────────────┼──────────────┐
   │              │              │
 左光敏L       右光敏R        上光敏U     下光敏D    ← 4×光敏模块(取 AO 模拟量)
   │              │              │
   └──────┬───────┘    ┌────────┴────────┐
          │            │                 │
     左右差动      上下差动               │
     (LM358)      (LM358)               │
          │            │                 │
     方向信号X     方向信号Y             │
          │            │                 │
          └─────┬──────┘                 │
                │                        │
          TB6612 双H桥                    │
        通道A→左右电机   通道B→上下电机   │
                │                        │
          传感器支架转动对准光源 ←───────┘  (机械反馈)
```

**反馈闭环**：传感器装在可转动的支架上 → 光源偏离 → 差分电压 → 电机转动 → 支架跟随光源 →
光敏重新对准 → 差分归零。这是一个典型的**负反馈位置伺服系统**。

## 3. 模块选型（基于手头已有模块）

| 模块 | 型号/构成 | 关键参数 | 来源 |
|------|----------|---------|------|
| 光敏传感器 | LM393 + 光敏电阻 5516 | 3.3~5V，AO 模拟输出，R1=10K 分压 | 模块资料/4-光敏电阻传感器 |
| 差动放大 | LM358 双运放 | 单电源 5V，轨到轨输出 | 需另购/或用 LM393 比较 |
| 电机驱动 | TB6612FNG | 双通道 H 桥，VM<10V，VCC 2.7~5.5V，峰值 3.2A | 模块资料/9-TB6612 |
| 直流电机 | 减速电机（N20 类） | 5V，减速比 1:30 | 需另购 |
| 电源 | 5V 稳压 / 锂电池 | 传感器+逻辑 5V，电机 VM 5V | 现有 |

> 光敏模块本身已集成 LM393 比较器（DO 数字输出 + AO 模拟输出）。本方案**用 AO 模拟输出**
> 做差分，故差动级需要额外运放（LM358）。也可直接用两个光敏模块的 DO 比较输出做开关式
> 跟踪（更简单但精度低）。本方案采用 AO 差分 + LM358，精度更高，控制分析更完整。

## 4. 光敏传感原理

光敏电阻 5516 特性：**光照越强，阻值越低**。

模块分压电路：
```
VCC ── R1(10K) ──┬── AO (模拟输出)
                  │
               光敏电阻 ── GND
```
$$V_{AO} = V_{CC} \cdot \frac{R_{ldr}}{R_1 + R_{ldr}}$$

- 光照强 → R_ldr 小 → V_AO 低
- 光照弱 → R_ldr 大 → V_AO 高

**差分信号**（左右轴）：
$$V_{diff\_x} = V_{AO\_R} - V_{AO\_L}$$
- 光源偏右 → 右亮 → V_AO_R 低 → V_diff_x < 0 → 电机右转
- 光源偏左 → 左亮 → V_AO_R 高 → V_diff_x > 0 → 电机左转
- 光源对准 → V_diff_x ≈ 0 → 电机停

上下轴同理：$V_{diff\_y} = V_{AO\_D} - V_{AO\_U}$。

> ⚠️ 注意极性：AO 与光照是反比，差分符号要按实际接法验证（可调换 LM358 输入）。

## 5. 控制理论意义（课设重点）

本系统是**位置伺服闭环**，可用经典控制理论分析：

- **被控对象**：直流电机 + 负载 → 一阶惯性环节 + 积分
- **传感环节**：光敏分压 → 一阶惯性（响应时间 ms 级）
- **差动放大**：比例环节 K_a
- **闭环**：负反馈位置环，可用传递函数/伯德图/根轨迹分析稳定性、超调、带宽

详细建模见 `3-控制分析.py` 和 `3-控制分析报告.md`。

## 6. 为什么不用单片机（设计说明）

课程要求禁止编程器件，考查**用模拟电路实现闭环控制**的能力：
- 光敏分压 = 传感 + 减法 = 误差检测
- LM358 差动 = 误差放大（比例控制 K_p）
- TB6612 = 功率驱动
- 机械反馈 = 闭环

整个系统就是一个"模拟 PID（本次取 P）控制器 + 被控对象"的实物化，与经典控制理论
教材的一阶/二阶系统章节完全对应。
