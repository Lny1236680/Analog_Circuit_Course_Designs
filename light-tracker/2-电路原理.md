# 点光源跟踪器 — 电路原理

> 电路图：`schem_tracker_full.png`（单轴示意，另一轴完全相同）

## 1. 光敏分压传感级

每个光敏电阻模块（LM393 + 5516）内部是标准分压：

```
VCC ── R1(10K) ──●── AO (模拟输出)
                  │
               光敏电阻 ── GND
```

$$V_{AO} = V_{CC} \cdot \frac{R_{ldr}}{R_1 + R_{ldr}}$$

- 光照强 → R_ldr 小 → V_AO **低**
- 光照弱 → R_ldr 大 → V_AO **高**

**双轴布置**：传感器装在可转动支架上，4 个光敏模块呈"十"字：
```
      上 U
  左 L   右 R    ← 左右差分 → X 轴电机
      下 D      ← 上下差分 → Y 轴电机
```

## 2. LM358 差动放大级（核心）

用 LM358 做**差分放大**，把左右两路光敏的差值放大：

```
AO_R ──Rin(10K)──→ (+)   LM358
                        │
AO_L ──Rin(10K)──→ (−)──┤Rf(100K)──→ Vout_X
                        │
                  Rm(10K)──GND  (匹配电阻, 改善 CMRR)
```

$$V_{out\_X} = \frac{R_f}{R_{in}}\left(V_{AO\_R} - V_{AO\_L}\right) = K_a \cdot V_{diff\_x}$$

取 Rf=100K、Rin=10K → **增益 K_a = 10**。

**作用**：
- 光源偏右 → 右亮 → V_AO_R 低 → Vout_X < 0 → 电机右转
- 光源偏左 → Vout_X > 0 → 电机左转
- 光源对准 → Vout_X ≈ 0 → 电机停

上下轴（Y）完全相同：$V_{out\_Y} = K_a(V_{AO\_D} - V_{AO\_U})$。

> 极性说明：AO 与光照成反比，所以"右亮"对应 V_AO_R 低。若接线后方向反了，
> 对调 LM358 的同相/反相输入即可（相当于差动信号取反）。

## 3. TB6612 驱动级

TB6612 双 H 桥驱动两个直流电机：

| TB6612 脚 | 接法 |
|-----------|------|
| VM | 电机电源 5V（或 7.4V 锂电池）|
| VCC | 逻辑 5V |
| STBY | 接 VCC（正常工作）|
| 通道 A: AIN1/AIN2/PWMA | 接 Vout_X 方向信号 + 固定 PWM |
| 通道 B: BIN1/BIN2/PWMB | 接 Vout_Y 方向信号 + 固定 PWM |
| AO1/AO2 | 左右电机 |
| BO1/BO2 | 上下电机 |

TB6612 真值表（通道 A）：
| AIN1 | AIN2 | 模式 |
|------|------|------|
| H | L | 正转 |
| L | H | 反转 |
| H | H / L L | 制动 |

**驱动逻辑**：Vout_X 的正负决定 AIN1/AIN2 状态 → 电机正/反转；PWMA 固定高电平（或
用 Vout_X 大小调制 PWM 实现比例速度）。方向用**滞回比较器**（LM393）把模拟差分转成
H/L 电平驱动 AIN1/AIN2，避免在零点附近抖振。

## 4. 完整单轴信号链

```
光 → LDR_L, LDR_R → 分压 AO_L, AO_R → 差动放大 ×10 → Vout_X
                                                        │
                              ┌── 滞回比较(LM393) ─→ AIN1/AIN2
                              └── 比例调速(PWM)  ─→ PWMA
                                                        │
                                                   TB6612 → 电机 → 支架转动 → 对准光源 (负反馈)
```

## 5. 电源

- **5V**：传感器 + LM358 + TB6612 逻辑（同一 5V，共地）
- **VM**：电机 5V（或 7.4V，电流大需独立电源，记忆 ESP32 项目的供电经验：避免大电流共用）

## 6. 去耦与实用细节

- LM358 电源脚加 0.1µF 去耦电容
- 光敏分压点加 100nF 滤波（模块上已有 C2）
- 电机两端反向并联二极管（TB6612 已内置，若用其他驱动需外接）
